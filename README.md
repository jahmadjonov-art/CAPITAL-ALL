# Capital Allocation Manager

A production-ready starter scaffold for the Capital Allocation Manager app (full-stack PWA).

Run locally:

1. Install dependencies:

```bash
npm install
npm run install-all
```

2. Seed the demo database (backend):

```bash
cd backend
npm run seed
```

3. Start backend and frontend (dev):

Backend:
```bash
cd backend
npm start
```

Frontend (dev):
```bash
cd frontend
npm start
```

This scaffold contains a simple Express + SQLite backend and a Vite + React frontend with PWA manifest.
More features will be implemented iteratively: allocation rules, offline sync, auth, exports, and reports.
